# Share the exercise with the class

The supplied `black-tech-nola-class-starter.zip` is ready to distribute as a file. It contains this source folder, the unchanged draft PowerPoint, presenter script, student instructions, sample checks, and labeled reference checkpoints. It excludes `node_modules`, backups, machine files, and test output. It starts with missing business behavior, not the completed answer loaded into `src/`.

## Direct distribution

Upload the ZIP to your existing event page, LMS, or shared folder. Download and extract it from that location once, then run the README quick start. Share the verified link on slide 11. No publication or message to the class has been performed by this package's creation.

Suggested accompanying text:

> Here is the starter from Beyond vibe coding at Black Tech NOLA. Extract the folder and start with README.md. Install Node 24, run npm ci, and follow docs/student-exercise.md. The project starts intentionally unfinished. The PowerPoint, presenter script, prompts and reference checkpoints are included. No AI API key is needed to run the app or checks.

## Optional GitHub repository

Create a repository in an account you control, then upload the extracted folder contents with README.md at the repository root. Exclude node_modules and .backups as configured by .gitignore. The actual URL depends on your chosen owner and repository name; this package does not assume either or publish a repository.

For a Git-based workflow, initialize this extracted project, add the source files and create a starter commit. Push to the repository you created. Verify its visibility matches the class's access and verify the download. You can enable GitHub's template-repository setting if you want students to create their own copies.

The included PowerPoint contains the supplied branding and artwork. No new blanket license has been applied to those assets or to this package. Choose any broader public licensing terms deliberately before public publication.

## Before sharing

Use a clean starter extraction, not your live-demo working directory. Verify Node 24, npm ci, and npm run test:harness. Make sure the README, docs and checkpoints are present. The ZIP is source-only and requires internet for initial dependency installation. After npm ci, this demo and its checks can run offline.
